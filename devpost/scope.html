SignedOff — AI Diff Comprehension Check

Status: Approved

Why It Matters

AI agents make it easy to ship code you can't explain. SignedOff turns "it works" into "I actually understand it" by requiring you to explain what changed, why the design works, and what happens on an edge case before unlocking a sign-off stamp.

The Core Loop (Sample-First Guaranteed Path)

Step 1 • Load

Click Load sample diff to populate the numbered login-hardening diff and unlock the 3 exam questions.

Step 2 • Answer

Explain what changed, why constant-time + dummy hash is used, and the proxy IP spoofing edge case.

Step 3 • Revise

Partial answers trigger red-pen line pointers on the exact diff lines missed so you can revise to Solid.

Step 4 • Stamp

Reaching 3 of 3 solid lands the rubber-stamp UNDERSTOOD badge and unlocks the Sign-Off note.

Scope Boundaries

Now (Guaranteed Path)

  • Bundled login-hardening sample diff loaded via button
  • Three pre-written questions & hidden rubric
  • Deterministic Solid / Partial / Missed verdicts + red-pen line pointers
  • Rubber-stamp Understood gate & sign-off export

Later (Stretch)

  • Paste your own diff with questions generated on the fly
  • Additional bundled diff scenarios
  • Git pre-push hook & PR comment bot

Cut (Out of Scope)

  • User accounts, sign-in, or cloud database
  • Full repository file tree browser
  • Chatbots that give away the answer
