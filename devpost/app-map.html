SignedOff — Architecture & Code Map

This map traces a single user action—checking an explanation—through the three core locations in index.html.

End-to-End Action Trace: "Check Answer" → Red-Pen Line Pointer → Stamp Unlock

1. index.html • gradeQuestion()

Input Capture: Reads the learner's explanation for q1, q2, or q3, validates non-empty text, and passes it to the rubric coverage matcher.

2. index.html • evaluateRubricCoverage()

Rubric Point Matcher: Evaluates which rubric criteria are covered and returns only an array of covered point IDs (e.g. ["q1_ratelimit"]).

3. index.html • deriveQuestionState()

Deterministic Verdict & Pointers: Pure code derives solid, partial, or missed, maps uncovered rubric IDs to red-pen diff line pointers, and unlocks the UNDERSTOOD stamp at 3/3.

Reusable Plan-First Takeaway: Never let a grader directly dictate UI state or line numbers. Have the grader report only which rubric points were covered, and let deterministic code compute the verdict chip, the red-pen line pointers, and the sign-off gate.
